# LinkedIn Outreach Assistant

Мини-CRM для подготовки персонального обращения в LinkedIn. Приложение хранит контакты, собирает черновик по вашему профилю и показывает текст, который можно скопировать.

Сообщения, приглашения и любые действия в LinkedIn выполняются только вами вручную. Здесь нет очереди отправки, планировщика, скрапинга, браузерной автоматизации и неофициального API LinkedIn.

## Установка

Из корня репозитория сначала перейдите в каталог приложения. В корне `package.json` нет, и `npm run dev` там завершается с ENOENT.

```bash
cd outreach
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

Приложение откроется на `http://localhost:3000`.

`npm run db:migrate` применяет миграцию из `prisma/migrations`. База создаётся рядом со схемой: `prisma/dev.db`.

## Переменные окружения

Отдельного `.env` в этой папке нет. Приложение читает корневой `.env` репозитория, тот же файл, что и бот. Для базы контактов в нём нужна строка:

```env
DATABASE_URL="file:./dev.db"
```

Ключ `OPENAI_API_KEY` берётся оттуда же. `OPENAI_MODEL` тоже общий с ботом; если строку убрать, черновики пойдут в `gpt-4o-mini`.

Профиль отправителя и источник контактов:

```env
LINKEDIN_PROFILE_URL="https://www.linkedin.com/in/your-profile/"
LINKEDIN_PROFILE_NAME="Your Name"
LINKEDIN_CONNECTIONS_CSV="C:\\path\\Connections.csv"
```

`LINKEDIN_CONNECTIONS_CSV` — путь к `Connections.csv` из архива LinkedIn. На компьютере: значок профиля → «Настройки и конфиденциальность» → «Конфиденциальность данных» → «Загрузка своих данных» → «Контакты» → «Запросить архив». Ссылка приходит на почту, внутри ZIP лежит `Connections.csv`. Прямой адрес страницы, если вы уже вошли в аккаунт: `https://www.linkedin.com/mypreferences/d/download-my-data`. На телефоне этого пункта нет. Без файла список контактов пуст: приложение не входит в LinkedIn и не забирает контакты со страницы.

## Что делает seed

`npm run db:seed` записывает профиль отправителя из `LINKEDIN_PROFILE_URL` и, если указан существующий файл, загружает из него контакты. Демонстрационные контакты при этом удаляются. Повторный запуск не затирает уже изменённые карточки. Без `LINKEDIN_CONNECTIONS_CSV` список контактов остаётся пустым.

## Импорт и экспорт

Импорт принимает CSV с колонками `fullName`, `linkedinId`, `linkedinUrl`, `headline`, `occupation`, `company`, `industry`, `location`, `interests`, `notes`. Обязательны имя, LinkedIn ID и род занятий. Несколько интересов в одной ячейке разделяются символом `|`. Разделитель колонок — запятая или точка с запятой.

Экспорт на странице «Контакты» выгружает те же поля плюс статус и дату ручной отправки.

## Генерация

На карточке контакта выбираются цель, тон, язык и необязательный контекст. Модель получает только сохранённые факты и пишет связный текст. Поле «Чем можете быть полезны» переносится без изменений. В ответе есть текст, использованные точки персонализации, риски для проверки и короткий follow-up. Перед статусом «Отправлено» приложение напоминает, что сообщение нужно отправить в LinkedIn самостоятельно.
